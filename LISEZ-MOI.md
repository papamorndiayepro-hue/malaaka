# Portfolio — Papa Mor Ndiaye

- `index.html` : le site complet (5 pages : Accueil, Projets, À propos, FAQ, Contact), FR/EN, objets 3D (three.js).
- `images/` : votre photo et les 3 images d’exemple (maquettes de référence, à remplacer par vos vrais projets).

## Admin caché
Cliquez 5 fois d’affilée sur « © Papa Mor Ndiaye » en bas de page.
- Version Claude (artifact) : l’admin s’ouvre seulement pour le propriétaire et enregistre dans la base de la plateforme (permanent).
- Ce dossier ouvert seul dans un navigateur : l’admin enregistre dans CE navigateur uniquement (localStorage). Pour des modifications permanentes visibles par tous, il faut un backend (FastAPI/Django + PostgreSQL).

## À faire
Remplacer les 3 projets d’exemple, vérifier le lien Snapchat (« malaaka mi »), écrire votre texte « À propos ».

## Code d’accès admin
Après les 5 clics, un code est demandé. À la toute première ouverture, vous créez votre code (4 caractères minimum, choisissez-en un long). Vous pouvez le changer dans l’admin (bouton « Code d’accès », puis « Publier »). Après 5 essais ratés, rechargez la page.
